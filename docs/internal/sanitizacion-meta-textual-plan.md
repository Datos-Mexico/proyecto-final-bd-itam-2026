## 2. Categorización y estrategias

### Categoría A — Patrones grep literales en bloques bash (5 matches)

**Naturaleza:** son el regex literal que el verificador ejecuta. Cada
patrón nombra explícitamente herramientas (claude, anthropic, cursor,
copilot, codeium) para que el grep las detecte.

**Estrategia recomendada: A2 (script separado).**

Crear `scripts/verify-clean-commits.sh` con el regex literal único. Los
3 docs referencian el script en lugar de incrustar el regex inline.

Ventajas de A2 sobre A1 (prose paraphrase) y A3 (variables abstractas):
- Preserva verificabilidad literal del check (el script es ejecutable).
- DRY: un solo source-of-truth para el regex en lugar de 5 copias.
- El verificador en sí mismo no es un artefacto narrativo del proyecto
  académico — vive en `scripts/`, separado de `docs/`. La verificación
  consolidada del prompt original ya excluye `scripts/` del check
  (`--exclude-dir=scripts`), lo que confirma que esta es la ubicación
  intencional para herramientas operacionales.
- Los docs quedan completamente libres del regex literal, sin perder
  reproducibilidad.

Nota: la frase entrecomillada "cero firmas en artefactos del

### Categoría C — Declaración primaria de política (1 match)

**Naturaleza:** `docs/disciplina-academica.md` líneas 45-47 contiene la
declaración constitucional del proyecto:

> "Cero firmas de sistemas de inteligencia artificial, asistentes
> automáticos, o herramientas de generación en cualquier artefacto del
> repositorio..."

Este match **NO es meta-textual**. Es la declaración primaria de la
política académica del proyecto. La frase "sistemas de inteligencia
artificial" describe genéricamente la familia de herramientas que la
política prohíbe firmar, sin nombrar marcas específicas.

**Decisión académica del CEO requerida.** Tres opciones:

- **C1 (sanitizar a lenguaje genérico):** reemplazar "sistemas de
  inteligencia artificial, asistentes automáticos, o herramientas de
  generación" por "herramientas externas de generación automática o de
  asistencia". Preserva el compromiso pero elimina la palabra
  "inteligencia artificial". Ventaja: coherencia constitucional
  completa. Desventaja: el lector externo puede interpretar "herramientas
  externas" como más amplio o más estrecho que la intención original.

- **C2 (preservar tal cual):** el match es la declaración primaria
  misma, no meta-textual. Su mención de "sistemas de inteligencia
  artificial" es académicamente honesta sobre qué tipo de herramientas
  la política contempla. Documenta sin atribuir.

- **C3 (reformular ampliamente):** "Cero firmas de cualquier herramienta
  externa de generación, asistencia o ejecución automática que pueda
  asistir en la producción de artefactos del repositorio." Preserva la
  amplitud del compromiso con lenguaje completamente neutral.

**Recomendación del agente:** C1 si el CEO quiere coherencia total con
el principio de "cero menciones de IA"; C2 si el CEO acepta la distinción
entre "declaración constitucional de la política" y "uso del lenguaje
de la política como firma". El agente no puede decidir esto
unilateralmente — es decisión académica fundacional.

## 3. Matriz literal de cambios propuestos (asumiendo C1 para Categoría C)

### 3.1 — Crear `scripts/verify-clean-commits.sh`

**Archivo nuevo**, ejecutable. Contenido propuesto:

```bash
#!/usr/bin/env bash
# Verificación: ausencia de firmas externas en commits.
#
# Ejecutar antes de cada `git commit` para confirmar que el área staged
# no contiene atribuciones a herramientas externas de generación o
# asistencia. Política completa en docs/disciplina-academica.md.
#
# Uso:
#   ./scripts/verify-clean-commits.sh
#
# Exit code:
#   0 — staged area limpia (cero matches).
#   1 — al menos una firma detectada (commit debe corregirse antes).

set -euo pipefail

REGEX='claude|anthropic|generated with|generated by|co-authored.*claude|🤖|AI[- ]?assist|made with claude|cursor|copilot|codeium'

if git diff --cached | grep -iE "$REGEX"; then
    echo "ERROR: firmas externas detectadas en staged area. Corregir antes de commit." >&2
    exit 1
fi

echo "OK: staged area sin firmas externas."
```

Marcar `chmod +x scripts/verify-clean-commits.sh`.
